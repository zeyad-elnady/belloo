# Product Images Reference Guide

## 📁 Image Location
All product images are stored in: `/public/assets/images/products/`

---

## 🎯 How to Use in Website Editor

When creating a product:

1. **Main Image (Glass Jars)**: Use the URL field (paste path)
2. **Gallery Images**: Use the URL fields for other packaging types

## ⚠️ Important Notes

1. **Copy exact paths** - Including spaces and capitalization
2. **Main image** should be from `GLASS JARS/` folder
3. **Gallery images** can be from any other packaging folder
4. Some products don't have all packaging types available
5. Use **URL paste field** (don't upload from device)

---
