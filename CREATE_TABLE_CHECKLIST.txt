□ STEP 1: OPEN SUPABASE DASHBOARD
  
  1. Go to: https://supabase.com/dashboard
  2. Log in to your account
  3. Click on your "Belloo" project


□ STEP 2: OPEN SQL EDITOR
  
  1. Look at the LEFT sidebar
  2. Click "SQL Editor" 
  3. Click "New Query" button (top-right corner)


□ STEP 3: COPY THE SQL CODE

  Copy EVERYTHING between the lines below:

─────────────────────────────────────────────────────────────────

-- CREATE TABLE FOR HOMEPAGE FEATURED PRODUCTS (CORRECTED FOR UUID)
CREATE TABLE IF NOT EXISTS homepage_featured_products (
  id SERIAL PRIMARY KEY,
  product_id UUID REFERENCES products(id) ON DELETE CASCADE,
  position INTEGER NOT NULL CHECK (position >= 1 AND position <= 6),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  UNIQUE(position)
);

CREATE INDEX IF NOT EXISTS idx_homepage_featured_position
ON homepage_featured_products(position);

ALTER TABLE homepage_featured_products ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read access" ON homepage_featured_products
FOR SELECT USING (true);

CREATE POLICY "Allow authenticated users to manage" ON homepage_featured_products
FOR ALL USING (auth.role() = 'authenticated');

─────────────────────────────────────────────────────────────────


□ STEP 4: PASTE AND RUN
  
  1. Click inside the SQL editor (the big text area)
  2. Paste the SQL you copied (Ctrl+V or Cmd+V)
  3. Click the green "RUN" button (▶) in the top-right
  4. Wait 2-3 seconds


□ STEP 5: VERIFY SUCCESS
  
  ✅ SUCCESS looks like:
     - Message says: "Success. No rows returned"
     - OR just: "Success"
     - No errors in red
  
  ❌ ERROR looks like:
     - Red text appears
     - Says "Error" or "Failed"
     - If you see an error, COPY IT and send it to me!


□ STEP 6: TEST THE FEATURE
  
  1. Go to: http://localhost:3000/website-editor
  2. Click the "Homepage" tab
  3. Select products from the dropdowns
  4. Click "Save Featured Products"
  5. You should see: "Featured products updated successfully!"
